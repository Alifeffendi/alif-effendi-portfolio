ABOUT THE PROJECT

Understanding Regions Through Spatial Data.

Regional Spatial Mapping is an academic project involving geographic data visualization and the representation of administrative boundaries using ArcMap.

The mapping process focuses on displaying regional boundaries through geographic layers, helping present spatial information in a visual and structured format.

This project represents an exploration of Geographic Information System tools and their application in urban and regional planning.
