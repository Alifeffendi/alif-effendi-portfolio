ABOUT THE PROJECT

Building a Bakery Experience.

Loafy Sunnie is a personal game development project created using Roblox Studio. The project explores the concept of a bakery business simulator where players can interact with ingredients, prepare bakery products, and experience different gameplay systems.

The development process focuses on building interactive mechanics, inventory management, cooking systems, and product decoration. The game is currently under development.
